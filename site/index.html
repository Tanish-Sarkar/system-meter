See what your machine is using.

Get started

One install.
One command.

Choose pip inside a virtual environment, or install an isolated command with uv.

  • Requires Python 3.13 or newer
  • Git is required for installing from the repository URL
  • Works on Windows, macOS, and Linux
  • The GitHub repository must be public for anonymous install
View project on GitHub ↗

Install with pip

Create a virtual environment, activate it, and install directly from GitHub.

Windows · PowerShell

py -3.13 -m venv venv .\venv\Scripts\Activate.ps1 python -m pip install git+https://github.com/Tanish-Sarkar/system-meter.git speakup

macOS · Linux

python3.13 -m venv venv source venv/bin/activate python -m pip install git+https://github.com/Tanish-Sarkar/system-meter.git speakup
Keep the virtual environment active to use speakup. To upgrade later, repeat the pip install command with --upgrade.

Install as a uv tool

uv installs the app in an isolated environment and exposes its command without activating a project environment.

uv tool install git+https://github.com/Tanish-Sarkar/system-meter.git speakup

If your shell cannot find speakup, add uv's tool executable directory to your PATH using uv tool update-shell, then restart the terminal.

Everyday usage

From quick check to live stream.

Run these after installing and activating your pip environment, or after installing with uv.

speakup

Show one colorful, human-readable system snapshot.

speakup --json

Print one versioned JSON snapshot for scripts and integrations.

speakup --quiet

Check collection silently; the exit status indicates success, not system health.

speakup doctor

Show collected information and limitations in a local report.

speakup watch

Refresh the human-readable view in an interactive terminal. Stop with Ctrl+C.

speakup watch --interval 5

Set watch refresh to 5 seconds (minimum 1 second; default 2 seconds).

speakup --json watch

Stream one JSON object per line. Redirect or pipe this output as needed.

speakup --help

See available commands and options.

Human-readable watch mode needs an interactive terminal. Use speakup --json watch for pipelines and redirected output.
Good to know

Clear answers before you install.

Why does development use uv run speakup?

It runs the command with the repository's uv-managed Python environment and dependencies. The command is not installed globally. Use a pip virtual environment or uv tool install if you want to type speakup directly in a new terminal.

Is System Meter a health or diagnostic score?

No. It reports metrics and collection limitations. It does not judge whether a system is healthy or apply universal thresholds.

Does every metric work on every computer?

No. Some details depend on the operating system and hardware. Optional values may be absent, and the tool reports collection warnings where available.

Does it send my system information anywhere?

No automatic telemetry or upload is built in. Review report contents before sharing them; filesystem mount points can reveal local details.
